# First Steps collection

This checked-in collection is shown by the Scene Builder dock when the `First Steps` palette is selected.

- `Woodland` contains the reusable moss boulder from the woodland kit.
- `Gameplay` contains the balance-beam preview item. It shows a beam in the editor and instantiates the existing `ParkourBalanceBeam` scene at runtime.

If the collection changes, use **Reload all items** in the Scene Builder dock. Placement uses generated collision surfaces; on Terrain3D, generate or rebuild terrain collision in the editor after sculpting before placing props.
